OmniOS Dukaan

The voice-first operating system for India's kirana stores.
Bolo, bill bano. Speak, and the shop runs itself.
In one line: the shopkeeper speaks an order in Hinglish; the app understands items, flavours and sizes, makes the bill, takes Cash / UPI / Udhaar, updates stock and the khata, and sends a professional e-bill on WhatsApp.

Live at omnidukaan.vercel.app · Demo shop code TEST, PIN 0000 · Confidential

1. The problem

  • 12M+ kirana stores run on memory, paper diaries and calculators.
  • Billing apps expect typing, menus and English; owners are busy, often 50+, one hand on the counter.
  • Udhaar (credit) is the shop's biggest risk and is tracked in a notebook.
  • Stock-outs and wrong prices cost money every day.

2. The idea

Voice first, zero training. One teal "Bolo" button on every screen. The owner talks the way they talk to a customer — "Sharma ji, do kilo cheeni, ek Maggi, aadha kilo toor dal" — and OmniOS does the rest. Everything else is one tap and large text.

PrincipleWhat it means
Speak, don't typeBills, stock-in, payments and questions all start with the voice.
Never block billingDoubts are asked inline ("Yahi wali? Haan / Nahi"); flavours are auto-picked with a "badlo" option.
Money is never pre-selectedCash / UPI / Udhaar is always the owner's tap.
Readable by everyoneText ≥18px, buttons ≥56px with icon + word, Hindi / Hinglish / English.
Data stays safeNothing is deleted without the owner; every shop sees only its own data.

4. Core features (live today)

Billing by voice

  • Speak the order → items, quantities, flavours and prices appear live.
  • Check step: unsure items get "Yahi wali? Haan / Nahi"; Nahi shows "which one?" with prices.
  • Pay step: Cash, UPI (large QR with amount filled in) or Udhaar with old → new khata balance.
  • Saved: one-tap WhatsApp e-bill, next bill, and undo.

Udhaar (credit) khata

  • Every customer's balance, history and a public khata link.
  • "Gupta ji ne 500 diye" records a payment by voice; WhatsApp reminders in one tap.

Stock (Maal)

  • "Maal aaya, 10 Aashirvaad atta" adds stock; supplier bill photo → stock + supplier dues.
  • Daily 3-item stock count with streak; "Cheeni kitni bachi?" answered aloud.

Hisaab & Home

  • Today's sales (Cash / UPI / Udhaar), who owes most, today's bills, morning briefing.
  • Galla check: "Galla mein 4,200 hai" matches the cash drawer to the bills.

Customer side

  • Professional e-bill (letterhead, items with flavour + size, total, payment status).
  • Online store page with ordering; order status page.

Admin dashboard

  • Create stores, reset PIN, pause/resume, phones logged in, bag requests, demand.

5. The Universe — product knowledge

1,500 items · 5,226 flavours and pack sizes sold in Indian kirana and supermarts, in Hindi, Hinglish and English with spoken mis-hearings. One default per item (e.g. Maggi → Masala 70g).
  • Flavour engine: picks the shop's usual flavour, else the default; asks only when a shop really sells a mix — never stops the bill.
  • Per-shop prices: from stock entry or manual, else learned after 3 bills at the same price; the owner can always change it.
  • Fast: loads once (~114 KB), cached on the phone, matching in ~4 ms per word.

6. Design

  • Final design "DF7", chosen after 7 rounds and a 13-member review panel (merchants, designers, accessibility, typography, Hindi, AI-detector).
  • Colour rules: ink = actions, teal = voice only, amber-brown = udhaar money only. Light and dark modes.
  • Fonts: Hanken Grotesk + Mukta (Devanagari), bundled for offline use.

7. How it is built

PartTechnology
AppReact + TypeScript + Vite, installable web app (PWA), hosted on Vercel
VoicePhone speech-to-text → rule-based Hinglish parser → AI fallback only when needed
DataSupabase (Postgres) with row-level security; all money changes run in server functions
SecurityShop code + PIN, lockout after 5 wrong tries, per-phone log-out
Quality85 automated tests; indexed database for speed

8. Business model (outline)

  • Free to start for a shop; paid plan for advanced features.
  • Distribution through local partners and supplier networks; free carry bags as a hook.
