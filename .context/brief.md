# Brief, compressed (full: ../PROJECT.md)
- Users: kirana owners who barely use phones (WhatsApp-level). Test question: could a 55-yr-old do it unaided?
- One mic everywhere → intent: bill ("Sharma ji, 2 kilo cheeni, 1 Maggi"), stock in ("Maal aaya…"), payment ("Gupta ji ne 500 diye"), question ("Cheeni kitni bachi?" spoken back), galla ("Galla mein 4,200").
- Voice flow: DICTATE (live words) → REVIEW card (unsure highlighted) → fix by tap/voice → ✓. Never save without ✓.
- Parser rules first (synonyms, fuzzy, units, Hindi numbers); Gemini only when unsure (server-side key).
- Phase 1 features: receipt photo→stock+supplier due; billing (no GST, cash/UPI recorded, walk-in ok); WhatsApp bill link page; udhaar ledger + reminder page; Aaj ka hisaab; galla match; 3-item stock check; morning briefing; streak; honest forecast ("Seekh raha hai"); store order site (pickup, QR poster); free ad bags request; admin (stores, PIN, usage, CSV, pitch line, read-only view, bags); T&C with data clause; hidden pitch-mode screen.
- Phase 2 (Coming soon): AI agents, khata OCR, offline, NBFC loans, profit. Phase 3: quick-commerce network.
- UX: ≤4 tabs, ≤2 taps from home, back button everywhere, text ≥18, buttons ≥56 icon+word, tap response <0.1s + sound/vibrate, motion 150–250ms, undo not confirm, warm friendly errors in owner language.
- Acceptance: 10 tap tests (PROJECT.md ACCEPTANCE) — run all before 3 Dec.
